Cases

The cases the treatises cite, ranked by how many editions in the treatise view cite each one. A case is a record in the Caselaw Access Project (CAP), the English Reports (Eng. Rep.), the Code Reporter (Code rep.), or a stub (Stub): a cite string no source holds, cited often enough to count. Works is how many different works the citing editions belong to, since a work of many editions weighs as many times in Editions.
